# CuteCute Rampage

A hyper-cute, hyper-violent pixel-art bullet-heaven/action roguelite built in Godot 4.6.

This repository is being bootstrapped as a playable vertical slice. The visual hook is sugary mascot-world pixel art colliding with exaggerated arcade gore; the gameplay goal is fast, readable, build-driven, and compulsively replayable.

## Current bootstrap goals

- Taffi player scaffold with `Skeleton2D`/`Bone2D` placeholder rig
- 32px seamless grass world with chunk streaming
- auto-fire + dash + XP + level-up loop
- cute projectile placeholders
- pixel blood, persistent splats, body stains, and dismemberment chunks
- enemy hordes + escalating director
- Cute Meter / combo feedback
- anime-style Special cut-in that pauses the world, then detonates a candy/gore screen clear

All placeholder visuals are generated in-engine so they can be replaced later without changing gameplay architecture.
